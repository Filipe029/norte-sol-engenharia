# NorteSol Engenharia - Landing Page

Landing page institucional e de alta conversão para a **NorteSol Engenharia**, especializada em sistemas de energia solar fotovoltaica para residências, empresas e agronegócio.

## ✨ Recursos

- **Design Responsivo & Moderno**: Adaptado para celulares, tablets e desktops.
- **Simulador Solar Interativo**: Cálculo em tempo real de economia e estimativa de investimento.
- **SEO & Performance**: Marcação semântica com Open Graph e Schema.org (`LocalBusiness`).
- **Captação de Leads**: Integração direta com WhatsApp e formulários otimizados.

## 🚀 Tecnologias

- **HTML5**
- **CSS3** (Design System com variáveis CSS e tipografia Montserrat / Inter)
- **JavaScript (Vanilla)**
